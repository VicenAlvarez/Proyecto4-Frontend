# Biblioteca

Catálogo de 8 sagas y 39 libros en español. Puedes buscar por saga o por título, ver la ficha de cada libro y guardar favoritos en el navegador.

Está hecho con React, Vite y CSS. Las fichas consultan Open Library para mostrar la editorial y el número de páginas cuando están disponibles.

## Cómo abrir el proyecto

Necesitas tener Node.js instalado. Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
npm install
npm run dev
```

Abre en el navegador la dirección que aparece en la terminal.
